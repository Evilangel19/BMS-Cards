The style sheets are loaded in this order by index.html (style-01 ... style-12): later rules override earlier ones, so keep the order.
style-11.css is only the Briefing tab of the Squadron page (every rule starts with .brw).
style-10.css is only the Settings window (every rule starts with #cfg, every class with s-).
style-12.css is only the Target tab of the Weapons page (every rule starts with .tgp, or .tgdlg for its Kneeboard window).
